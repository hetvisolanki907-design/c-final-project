# City Bus Management System

A simple C++ project designed to manage bus information and help users search for buses easily.

## Features
- View all registered buses
- Search buses by bus number
- Search buses by source and destination
- Count total registered buses
- Save and load bus details using file handling

## Concepts Used
- Object-Oriented Programming (OOP)
- Encapsulation, Abstraction, Inheritance, and Polymorphism
- Classes, Objects, and Constructors
- Vectors and Functions
- File Handling and Input Validation

## Technologies
- **Language:** C++
- **Storage:** Text File (`buses.txt`)

## Future Improvements
- Real-time bus tracking
- Database integration
- User-friendly graphical interface

## Purpose
This project demonstrates basic C++ programming and OOP concepts through a practical bus management application.
